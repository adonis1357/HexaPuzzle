# 「활」(Hwal) 프로젝트 브리프 — PM 공통 기준 문서

> 모든 파트(기획/프로그램/아트/사운드)는 이 문서의 **확정 사항**을 기준으로 작업한다.
> 파트별 사양서는 이 문서를 상세화하되, 확정 수치를 바꾸려면 "변경 제안" 섹션에 근거와 함께 기록한다.

## 1. 한 줄 정의

**실시간 1:1 궁수 대전.** 바람이 강하게 부는 들판에서 두 궁수가 마주 서서, 각도·힘·정확도(추 타이밍)를 맞춰 상대를 먼저 쓰러뜨린다. 턴제가 아니라 실시간이며, 사격 후 **장전 딜레이**가 있고, 딜레이가 끝난 뒤 **얼마나 오래 호흡을 골랐는지(초과 대기)** 에 따라 다음 딜레이가 줄어든다 (정점 10초, 그 이후 효율 감소).

## 2. 확정 사항 (프로토타입 범위)

| 항목 | 확정 값 |
|------|--------|
| 엔진 | Unity 2022.3.62f2, 별도 프로젝트 폴더 `Bow/` |
| 화면 | 모바일 세로(Portrait) 1080×1920 기준, 한 손 터치 플레이 (에디터에서는 마우스) |
| 렌더링 | 2D 사이드뷰. SpriteRenderer + 런타임 생성 Texture2D, LineRenderer(활/궤적), uGUI HUD. **외부 아트 에셋 없음 (전부 프로시저럴)** |
| 폰트 | Unity 내장 LegacyRuntime.ttf (OS 폴백으로 한글 표시) |
| 네트워크 | `IMatchTransport` 추상화. 기본: 봇 대전(`LocalBotTransport`). LAN TCP 호스트/참가(`LanTcpTransport`). 호스트가 데미지 판정 권위(authority) |
| 결정론 | 바람 = (seed, 경기시간)의 순수 함수. 화살 = 고정 스텝 적분 → 양쪽 클라이언트 동일 결과 |

### 2.1 경기 규칙
- 각 궁수 HP **100**. 데미지: 몸통 **25**, 머리 **40**. 정확도 "완벽(Perfect)" 시 ×1.25.
- 제한 시간 **120초**. 시간 종료 시 HP 높은 쪽 승, 동률 무승부.
- 사거리(두 궁수 간 거리) **16~24 m** 랜덤(seed), 높이 차 **±1.5 m** 랜덤.
- 플레이어는 항상 화면 왼쪽, 상대는 오른쪽. (네트워크 시 각자 자신의 화면에서 왼쪽)

### 2.2 조준 입력 (한 손)
1. 화면 아무 곳이나 **드래그** → 당기는 방향의 반대로 조준 (앵그리버드 방식). 드래그 각도 = 발사 각도, 드래그 길이 = 힘(0~1).
2. 손을 떼면 **정확도 추(錘) 미터** 시작: 추가 좌↔우로 왕복 (주기 1.1초). 
3. **탭**하면 발사. 추의 중앙 오프셋 p ∈ [-1, 1] → 각도 오차 = p × 6°. |p| < 0.08 이면 **Perfect**.
4. 3초 내 탭하지 않으면 현재 위치로 자동 발사.
- 조준 가이드: 바람을 무시한 초기 0.5초 궤적만 점 3개로 표시 (바람 보정은 플레이어의 감각에 맡김).

### 2.3 탄도 & 바람
- 중력 9.81 m/s². 화살 초속 **v = 9 + 13 × 힘** (9~22 m/s).
- 바람 w(t) [m/s, +는 오른쪽] = **구간형** (플레이테스트 피드백 반영): 8초마다 seed 기반 목표값(크기 0.5~7, 부호 랜덤)으로 바뀌며, 변화는 2.5초 동안 smoothstep으로 진행. HUD에 현재 바람 + 다음 바람 미리보기 + 변화까지 남은 초 표시. (초기안: 3중 사인파 합성 — 변화가 너무 빨라 폐기)
- 화살 수평 가속도 **a_x = 0.6 × w(t)** (매우 강한 영향: 2초 비행 시 최대 ≈ 7 m 횡이동).
- 바람은 양쪽 공통, 매 순간 변함. HUD에 풍향·풍속 표시 (깃발/화살표 + 숫자).

### 2.4 장전 딜레이 & 호흡(Breath) 시스템 ★핵심
- 기본 딜레이 **B = 5.0초**. 발사 시각 t_f, 장전 완료 시각 t_r = t_f + D_현재.
- **초과 대기 h** = (다음 발사 시각) − t_r (장전 완료 후 추가로 기다린 시간, h ≥ 0).
- **호흡 효율 E(h) = (h/P) · e^(1 − h/P)**, 정점 **P = 10초** (E(10)=1.0, E(5)=0.82, E(20)=0.74, E(30)=0.41, E(0)=0).
- **다음 딜레이 D_next = B × (1 − 0.7 × E(h))** → 최소 1.5초(정확히 10초 기다렸을 때).
- 보너스: 호흡 효율이 높을수록 추 미터가 느려짐 — 추 주기 = 1.1 × (1 + 0.3·E).
- 즉, "10초 기다렸다가 쏘면 1.5초 뒤 바로 한 발 더" 리듬이 생긴다. 20초 이상 기다리면 손해.
- HUD: 장전 중엔 링이 줄어들고, 장전 완료 후엔 금색 호흡 링이 10초까지 차오른 뒤 서서히 회색으로 식는다. 수치 표시.

### 2.5 상대 봇
- 탄도 역산 + 바람 추정(현재 바람의 70%만 반영) + 가우시안 오차(난이도별 σ). 호흡 시스템도 동일하게 사용(랜덤 h 선택: 6~13초).

## 3. 아트 방향 (확정)
- 컨셉: **「먹과 한지」** — 한국 전통 국궁 대결을 미니멀 잉크 실루엣으로.
- 팔레트: 한지 `#F3EAD3`, 먹 `#1E1B18`, 주사(朱砂) `#B5312B`(플레이어), 쪽빛 `#2F5D8A`(상대), 금박 `#C9A227`(호흡/Perfect), 회색 먹 `#8A857C`(비활성).
- 궁수 = 실루엣(원 머리 + 사각 몸통/팔다리), 활 = LineRenderer 호(弧), 화살 = 가는 막대 + 삼각 촉 + 깃.
- 바람 = 화면을 가로지르는 가는 먹선 스트로크 입자(속도·밀도 = 풍속).
- 모든 이펙트는 Texture2D/LineRenderer/스케일·알파 트윈으로 구현 (코루틴 + 이징).

## 4. 사운드 방향 (확정)
- **BGM은 Suno AI로 제작** (로비 / 대전 / 승리 / 패배 4트랙). 사운드 디렉터가 Suno 프롬프트·태그·길이·루프 가이드를 작성.
- 파일 배치: `Bow/Assets/Resources/Audio/BGM/<이름>.ogg|mp3|wav`, SFX는 `Bow/Assets/Resources/Audio/SFX/<이름>.wav`.
- SFX는 파일이 없으면 **프로시저럴 합성 폴백**(HexaPuzzle의 ProceduralAudio 패턴)으로 재생.
