# 「활」 캐릭터 파트 DSL (디자인 팀 ↔ 프로그램 팀 규격)

> 캐릭터는 코드 수정 없이 `Bow/Assets/Resources/Characters/characters.json` 데이터만으로 추가된다.
> 모든 그래픽은 프로시저럴 기본 도형(사각/원/삼각/소프트원/링)과 선(LineRenderer)으로만 그린다. 외부 이미지 없음.
> 단위: **m** (궁수 키 1.91 m 기준), 각도 **°**, 색은 역할 이름 또는 `#RRGGBB`.

## 1. 기본 골격 (모든 캐릭터 공통, 오른쪽을 바라봄)
| 앵커 | 루트 기준 위치 (m) | 설명 |
|------|------------------|------|
| `feet` | (0, 0) | 발 중앙(지면) |
| `belt` | (0, 1.10) | 허리띠 중앙 |
| `torso` | (0, 1.13) | 몸통 중심 (몸통 0.50 × 0.66) |
| `back` | (−0.25, 1.20) | 등 (몸통 뒤에 그려짐) |
| `head` | (0.03, 1.72) | 머리 중심 (기본 원 반지름 0.21) |
| `bow` | 활 그립 (조준 각도에 따라 회전) | 활과 함께 회전·이동 |

파트의 `x, y` 는 **앵커 기준 오프셋**. 앞쪽(+x)이 상대 방향. 상대 캐릭터는 자동으로 좌우 반전된다.

## 2. 캐릭터 JSON 스키마
```json
{
  "characters": [
    {
      "id": "fox",                  // 영문 소문자, 고유
      "name": "불여우",              // 표시 이름 (한국어, 2~5자)
      "theme": "동물",               // 동물 / 메카닉 / 곤충 / 신화 / 기타
      "desc": "바람을 읽는 들판의 사냥꾼",   // 한 줄 소개 (20자 내외)
      "bodyColor": "#1E1B18",       // 몸통/팔다리/머리 기본색 (먹 계열 또는 테마색)
      "accentColor": "#D4554D",     // 포인트색 (파트 color "accent")
      "headShape": "circle",        // circle | oval | square | tri
      "headScale": [1.0, 1.0],      // 머리 크기 배율 (x, y)
      "bowStyle": "classic",        // classic | recurve | longbow | mech
      "bowColor": "body",           // 활 색: body | accent | team | #hex
      "parts": [ ...아래 파트 객체... ]
    }
  ]
}
```

## 3. 파트 객체
```json
{ "kind": "tri", "anchor": "head", "x": -0.05, "y": 0.22, "w": 0.16, "h": 0.30,
  "rot": 70, "color": "body", "order": 1, "mirrorX": true, "name": "귀" }
```
| 필드 | 값 | 설명 |
|------|----|------|
| `kind` | `rect` / `circle` / `tri` / `soft` / `ring` | 사각 / 원 / 삼각(기본 +x 방향을 가리킴) / 소프트 원(흐린 가장자리) / 링 |
| `anchor` | `feet` / `belt` / `torso` / `back` / `head` / `bow` | 붙는 위치 |
| `x`, `y` | m | 앵커 기준 오프셋 |
| `w`, `h` | m | 크기 (원/링은 지름) |
| `rot` | ° | 반시계 회전 |
| `color` | `body` / `bodyDark` / `bodyLight` / `accent` / `team` / `paper` / `#RRGGBB` | 색 역할 |
| `alpha` | 0~1 (기본 1) | 투명도 |
| `order` | −3 ~ +3 | 그리기 순서 (0 = 몸통과 같은 층, 음수 = 뒤, 양수 = 앞) |
| `mirrorX` | true/false | 앵커 세로축 기준 좌우 대칭 복제 (귀·뿔·날개 쌍) |
| `name` | 문자열 | 설명용 (선택) |

**제한**: 캐릭터당 파트 **6~14개** (mirrorX 복제는 1개로 셈). 전체 실루엣 높이 2.6 m 이하, 폭 1.4 m 이하. 머리 판정(반지름 0.30)과 몸통 판정(±0.30 × 0~1.48)은 공통이므로 파트가 판정에 영향 주지 않음을 디자인 문서에 명시.

## 4. 색 역할
- `body` = `bodyColor`, `bodyDark` = 20% 어둡게, `bodyLight` = 25% 밝게
- `accent` = `accentColor`
- `team` = 플레이어 주사(#B5312B) / 상대 쪽빛(#2F5D8A) — 허리띠·머리띠·화살 깃은 항상 team (팀 식별용)
- `paper` = 한지 (#F3EAD3) — 눈 흰자, 하이라이트 등

## 5. 활 스타일
| 값 | 모양 |
|----|------|
| `classic` | 현재 기본 호 (R 0.85→0.72, 폭 0.07) |
| `recurve` | 짧고 굵은 호 (R 0.65, 폭 0.09), 끝이 바깥으로 살짝 휨 |
| `longbow` | 길고 가는 호 (R 1.05, 폭 0.05) |
| `mech` | 각진 5점 직선 활 (폭 0.09), accent 색 테두리 느낌 |

## 6. 디자인 가이드 (먹과 한지 컨셉 유지)
- 실루엣이 **한눈에 구분**되어야 한다 (귀/뿔/더듬이/날개/꼬리/장갑판 등 1~2개의 대표 형태).
- 색은 **몸통 1색 + 포인트 1색**. 포인트는 작게. 팀색과 충돌하지 않도록 주사/쪽빛 계열 피하기.
- 눈: `circle` paper 0.07 + `circle` body 0.035 조합 권장 (head 앵커, x +0.08).
- 메카닉: 장갑판은 `rect` bodyLight/accent, 관절은 `ring`, 안테나는 `rect` 얇게.
- 곤충: 더듬이 `rect` 얇게 + 끝 `circle`, 날개는 `soft` alpha 0.5 back 앵커, 겹눈은 `circle` 크게.
