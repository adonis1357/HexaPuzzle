# UI 전면 재디자인 프로그램 — 검증 체크리스트 & 로드맵

> 2026-06-15 멀티에이전트 토론(전수조사 → 6 페르소나 제안 → 적대적 비평 → 최종화)으로 수립.
> 각 화면을 이 체크리스트로 검증 루프를 돌려 출시 품질 게이트를 통과시킨다. P0=필수, P1=중요, P2=권장.

## 검증 체크리스트 (13개 범주)

### 1. 정보위계·가독성 (VH)
- **VH-1 (P0)** 화면당 1차 초점 요소 1개만, 시각가중치 2순위의 1.5배↑. (가중치=폰트px×max(HSV-S,0.35)×글자면적px²)
- **VH-2 (P1)** 라벨 ≤ 값 (폰트/굵기/채도). 핵심 HUD 값÷라벨 폰트비 ≥1.5. 긴 숫자(9자리)에서도 역전 0.
- **VH-3 (P1)** 위급 상태(잔여≤3·MP부족·콤보) 경고가 심각도순 단조 강화. 강도=0.4·Δalpha+0.4·min(Hz/3,1)+0.2·스케일폭.

### 2. 정보구조·내비 (IN)
- **IN-1 (P1)** HUD 독립 클러스터 ≤5개(7±2). 같은 기능부류는 1클러스터.
- **IN-2 (P0)** 클릭가능 요소 중 "준비중 토스트 종결" dead-end ≤15%. (전수 클릭 테스트, FC와 공유)
- **IN-3 (P1)** 활성 탭/모드를 색 외 형태단서(밑줄/하이라이트)로 표시. 그레이스케일에서도 구분.
- **IN-4 (P1)** 로비 첫 화면에 일일보상 진입점 상시 + 미수령 인디케이터.

### 3. 시각일관성·토큰 (VC)
- **VC-1 (P1)** 골드 단일토큰(1,0.816,0.420), 한 화면 두 팔레트 혼용 0, 텍스트색 하드코딩 0. (grep 전수)
- **VC-2 (P2)** 같은 기능부류는 형태·색의미·모션속도 공유(게이지/수치/배지).

### 4. 보드 가독성·젬 구분 (BD)
- **BD-1 (P0)** 11종 젬을 색 외 단서(형태/심볼/패턴)로 구분. 색맹 시뮬 ΔE(CIEDE2000)<12 쌍은 비색채 단서 필수. (HexBlock에 현재 전무)
- **BD-2 (P1)** 티어(Normal→Tier3→ProcessedGem)를 형태/장식/광택으로 구분. 그레이스케일 5단계 구분.
- **BD-3 (P1)** 특수블록 5종: 생성 예고 인디케이터 + 종류 구분 + 드릴 방향(Vertical/Slash/BackSlash) 예고.

### 5. 회전·클러스터 어포던스 (RC)
- **RC-1 (P0)** 선택된 3블록 삼각 클러스터를 즉시 하이라이트(대비 3:1↑). 선택 피드백 부재 = 실패.
- **RC-2 (P1)** 회전 방향(CW/CCW) 단서 + 매치 실패 롤백 피드백.
- **RC-3 (P2)** 무효 영역 터치 시 의도치 않은 상태변화 0.

### 6. 적(고블린) 상태 가독성 (EN)
- **EN-1 (P0)** HP바/수치 별도 레이어, occlusion α0.5에도 판독, 폰트≥12pt.
- **EN-2 (P1)** 고블린 다음 행동/공격 대상칸/궁수 사정거리 턴 전 예고.
- **EN-3 (P1)** 쉘블록(회색+크랙) 구분, 낙하 데미지 예측 단서.

### 7. 턴·캐스케이드 진행 상태 (TP)
- **TP-1 (P1)** Playing/Processing 구분, 캐스케이드 중 처리중 표시, 입력 재개 신호.
- **TP-2 (P2)** 8초 스턱복구 시 프리즈처럼 안 보이게 + 정상 전이.

### 8. 모바일 사용성·탭타겟 (MU)
- **MU-1 (P0)** 모든 탭 히트영역 ≥9.0mm(≈44dp), 인접 중심간격 ≥8dp. dp 환산으로 판정.
- **MU-2 (P1)** 빈번 1차액션(아이템/PLAY/회전영역/일시정지)을 엄지영역(하단 75%)에. 상단25%·반대코너 금지.
- **MU-3 (P0)** 본문≥14pt, 라벨/캡션≥12pt, 11pt 미만 0. auto-size는 최장입력 기준.

### 9. 피드백·모션 (FB)
- **FB-1 (P0)** 자원피드백 통합: MP/골드 부족 시 차단+빨강플래시+흔들림+의도치않은 진행 0 / 재화 증감 카운팅+인게임↔로비 동기화.
- **FB-2 (P0)** 점멸/펄스 ≤3Hz(WCAG 2.3.1), 정지프레임 판독, 깜박임만으로 핵심정보 전달 금지.
- **FB-3 (P2)** 준비중 토스트: 연타 시 1개 유지/교체, 1.5~3초, 핵심 CTA 안 가림.

### 10. 청각 피드백·무음 대체 (AU)
- **AU-1 (P2)** 핵심 상호작용 사운드 존재·구분, 캐스케이드 시 과다중첩 방지.
- **AU-2 (P1)** 모든 청각 신호를 시각 채널로 중복. 사운드 유일 채널 사건 0.

### 11. 접근성 (AC)
- **AC-1 (P0)** 본문 대비 4.5:1, 큰 텍스트 3:1 (WCAG AA). 스크림 α0.45 합성 최악배경 산식으로 판정.
- **AC-2 (P1)** 상태색(난이도/획득별/잠금/배지) 대비 3:1 + 색 외 단서 1개↑(색맹 ΔE≥12).

### 12. 플로우 정합성·수익화 동선 (FC)
- **FC-1 (P0)** 헤더 재화칩(골드/하트/젬)은 실제 동작 재화만. 준비중 토스트 종결 칩 0.
- **FC-2 (P1)** 수익화 진입점은 3탭 내 구매화면 또는 가격/혜택 프리뷰. 단일 토스트 종결 0.
- **FC-3 (P1)** 로비 첫화면 1순위 CTA(히어로) 1개만 최고강조. 골드/주황 최고강조 2개↑ = 실패.
- **FC-4 (P1)** 게임오버 결제: 동등 가시성 거절경로 + 가격급등 사전노출 + 강제포커스/타이머 0 (다크패턴 방지).
- **FC-5 (P1)** 인게임 구매버튼: 비용·수량·단위(G/MP) 명시 + 부족 시 비활성/경고.

### 13. 온보딩·엣지케이스·성능 (OE)
- **OE-1 (P1)** 첫 회전/특수블록/아이템/고블린 도입 시 적시 튜토리얼 + 스킵 + 재진입.
- **OE-2 (P1)** 클리어 보상: 증가 애니메이션 + 최초/재클리어 분리표기 + 보상0 안내.
- **OE-3 (P1)** 런타임 AddComponent UnityEvent(onUsed 등) 명시 초기화 → 첫 클릭부터 정상.

## 실행 로드맵 (10단계, 의존성 순)

| Step | 화면 | 핵심 근거 | 산출물 |
|---|---|---|---|
| **1** | **디자인 토큰 통합 + 공용 컴포넌트 팩토리** | LobbyTheme/UITheme/ClaudeTheme 3종 공존, HUD는 토큰 미사용 RGBA 하드코딩. 컴포넌트 헬퍼 부재 → 화면마다 인라인 복붙. 0순위. | 토큰시트+컴포넌트 카탈로그 목업 / `UIFactory` 정적 팩토리(MakeGlassPanel/Chip/HudFrame/Primary·SecondaryButton/Badge/LabeledValue/ProgressBar) |
| **2** | 로비 스테이지 버튼 + 점수표시 마감 | 노드만 단순 Image, BEST/MY 하드코딩(#FFD86B). 첫 화면·80% 완성, 팩토리 첫 실전. | 글래스 노드 3상태 목업 / StageScrollBuilder 토큰화 |
| **3** | 인게임 HUD 상단(MOVES·SCORE·난이도·골드) | 4블록 흩어짐, 위계 약함, RGBA 하드코딩. 최고 트래픽 표면. | HUD 통합 레이아웃 / GameManager HUD 생성부 토큰화 |
| **4** | 인게임 우측 게이지(MP+아이템 ChargeBar) | MP/ChargeBar/턴프레임 디자인 언어 혼재. | 게이지존 통일 목업 / MPGaugeUI·ChargeBarController 토큰화 |
| **5** | 동적 피드백(콤보+점수/골드 팝업) | 이벤트 모션 레이어, 정적 색 굳은 뒤 조화. | 콤보 단계별 모션 시트 / ComboDisplay·팝업 토큰화 |
| **6** | 보드·젬·클러스터 어포던스 | 젬 색 구분/회전 하이라이트/고블린 가독성 — 가장 본질적. HUD 독립. | 젬 구분·회전 힌트·고블린 상태 시트 / HexBlock·InputSystem·GoblinSystem |
| **7** | 전체화면 오버레이(일시정지·설정·도움말·무한미션) | 모달 계열, 팩토리 재사용. | 모달 공통 셸 / UIManager 팝업 토큰화 |
| **8** | 결과·보상(클리어/게임오버/점수 브레이크다운) | 연출 비중 큼, 수익화 진입점. | 클리어·게임오버 목업 / 팝업 토큰 셸 |
| **9** | 수익화·재화 동선(구매·구독 팝업) | 흩어진 구매 플로우, 헤더 칩 연결. | 구매 모달 패턴 / 구매 팝업 통일 |
| **10** | 온보딩·접근성·성능 마감(횡단) | 전 화면 확정 후 전역 패스. | 코치마크·색약·탭타겟 가이드 / 전역 감사 |

**진행 방식**: 각 step = ① Claude 디자인 목업 → ② 검증 루프(위 체크리스트 해당 범주, P0 전부 통과까지) → ③ Unity 구현 → ④ 컴파일+갱신 테스트. step1 완료 후 모든 step은 UIFactory만 호출.
