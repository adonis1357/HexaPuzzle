### Step 1: 기존 구조 확인

현재 구조: **80스테이지, 8챕터** (10스테이지/챕터)

| 챕터 | 스테이지 | 테마 | 난이도 |
|------|---------|------|--------|
| 1 | 1~10 | 크리스탈 숲 | Easy |
| 2 | 11~20 | 얼음 협곡 | Easy→Normal |
| 3 | 21~30 | 화염 동굴 | Normal |
| 4 | 31~40 | 독안개 늪 | Normal |
| 5 | 41~50 | 사막 유적 | Normal→Hard |
| 6 | 51~60 | 심해 신전 | Hard |
| 7 | 61~70 | 어둠의 성 | Hard |
| 8 | 71~80 | 마법사의 탑 | Hard |

몬스터 등장 순서: 기본→갑옷→궁수→방패→폭탄→힐러→헤비→마법사

### Step 2: Mission1StageData.cs

**파일**: `Assets/Scripts/Data/Mission1StageData.cs`

스테이지별 `StageData` 정의:
```csharp
new StageData {
    stageNumber = N,
    chapterNumber = C,
    chapterName = "챕터명",
    turnLimit = 15~25,       // 턴 제한
    difficulty = 1~3,         // 1=쉬움, 2=보통, 3=어려움
    missions = new[] {
        new MissionData {
            type = MissionType.RemoveEnemy,
            targetEnemyType = EnemyType.Goblin,
            targetCount = 5,
            description = "고블린 5마리 처치"
        },
        // 최대 6종 미션
    }
}
```

**미션 타입 참조:**
- `RemoveEnemy` — 몬스터 처치 (targetEnemyType 지정)
- `CollectGem` — 블록 수집 (targetGemType 지정)
- `CreateBomb/CreateDrone` — 특수 블록 생성
- `TriggerBigBang` — 빅뱅 발생

**주의**: 미션 최대 6종 제한 (초과 시 자동 재분배)

### Step 3: LevelRegistry.cs

**파일**: `Assets/Scripts/Data/LevelRegistry.cs`

레벨 등록 함수 추가:
```csharp
private static void RegisterStagesNToM()
{
    for (int i = N; i <= M; i++)
    {
        Register(new LevelData {
            levelId = i,
            levelName = $"LEVEL {i}",
            subtitle = "부제목",
            gameMode = GameMode.Stage,
            difficultyType = DifficultyType.Easy/Normal/Hard,
            isLocked = true,
            unlockRequirement = i - 1,
        });
    }
}
```

`RegisterLevels()`에서 새 함수 호출 추가.

### Step 4: GameManager.cs — GetGoblinConfigForStage

**파일**: `Assets/Scripts/Managers/GameManager.cs`

스테이지별 몬스터 소환 설정:
```csharp
case N: return new GoblinStageConfig {
    minSpawnPerTurn = 1~4,    // 턴당 최소 소환
    maxSpawnPerTurn = 1~7,    // 턴당 최대 소환
    missionKillCount = 총합,   // 미션 목표 합계
    maxOnBoard = 3~14,        // 보드 최대 동시
    archerRatio = 0~0.3f,     // 궁수 비율
    armoredRatio = 0~0.3f,    // 갑옷 비율
    shieldRatio = 0~0.2f,     // 방패 비율
    heavyRatio = 0~0.15f,     // 헤비 비율
    archerHp = 1,
    armoredHp = 10~20,
    shieldGoblinHp = 8~15,
    shieldHp = 2~4,
    bombGoblinHp = 8~15,
    heavyGoblinHp = 30~50,
};
```

### Step 5: 밸런스 가이드

**난이도 곡선:**
- 초반 (1~10): 턴 15~20, 미션 1~2종, 기본 몬스터만
- 중반 (21~50): 턴 18~22, 미션 2~4종, 복합 몬스터
- 후반 (51~80): 턴 15~20, 미션 3~6종, 고난도 조합
- 보스 (X5/X0): 높은 missionKillCount, maxOnBoard 12~14

**몬스터 밸런스:**
- `missionKillCount` = 모든 미션의 targetCount 합계
- `maxOnBoard` ≤ `missionKillCount` (보드가 미션보다 크면 안 됨)
- 보스 스테이지: `minSpawnPerTurn` 3~4, `maxSpawnPerTurn` 5~7
