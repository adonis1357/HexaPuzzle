## 몬스터 체크리스트

$ARGUMENTS

기존 몬스터 패턴을 반드시 따릅니다. 모든 응답은 한국어로 작성합니다.

---

### Step 1: 기존 패턴 확인

현재 8종 몬스터 (Assets/Scripts/Core/GoblinSystem.cs):

| 타입 | EnemyType | 특징 |
|------|-----------|------|
| 기본 고블린 | Goblin(10) | 기본형, 블록 공격 |
| 갑옷 고블린 | ArmoredGoblin(11) | 높은 HP |
| 활 고블린 | ArcherGoblin(12) | 최상단 배치, 원거리 공격 |
| 방패 고블린 | ShieldGoblin(13) | 방패 내구도, 드릴 차단 |
| 폭탄 고블린 | BombGoblin(14) | 카운트다운 후 폭발 |
| 힐러 고블린 | HealerGoblin(15) | 아군 HP 회복, 단독 시 블록필드 진입 |
| 헤비급 고블린 | HeavyGoblin(16) | 3블록 삼각형 점유, 높은 HP |
| 마법사 고블린 | WizardGoblin(17) | 소환 영역 전용, 파이어볼+번개 |

공통 구조:
- `GoblinData` 필드: `bool isXxx`, HP, 턴 카운터
- `GoblinStageConfig` 필드: `float xxxRatio`, `int xxxHp`
- 행동 패턴: `XxxGoblinPhase()` 코루틴
- 프로시저럴 스프라이트: `CreateXxxGoblinSprite(int size)`

### Step 2: EnemyType 추가

**BlockData.cs** (Assets/Scripts/Data/BlockData.cs):
- `EnemyType` enum에 새 값 추가 (다음 번호: 18)

### Step 3: GoblinData + 소환 로직

**GoblinSystem.cs** (Assets/Scripts/Core/GoblinSystem.cs):
1. `GoblinData` 클래스에 타입 플래그 추가: `public bool isNewType;`
2. `SpawnWaveBatch()`에 소환 분기 추가 (타입별 가중 랜덤)
3. 위치 배정 규칙 추가 (궁수=상단, 방패=하단, 나머지=중간)
4. 프로시저럴 스프라이트 생성 메서드: `CreateNewTypeGoblinSprite(int size)`
5. 행동 패턴 코루틴: `NewTypeGoblinPhase()`
6. `GoblinPhase()`에서 새 타입 분기 추가

### Step 4: GoblinStageConfig 확장

**GoblinSystem.cs** 상단 `GoblinStageConfig` 클래스:
- `public float newTypeRatio = 0f;` — 소환 확률
- `public int newTypeHp = 10;` — 기본 HP

### Step 5: GameManager 연동

**GameManager.cs** (Assets/Scripts/Managers/GameManager.cs):
1. `GetGoblinConfigForStage()`: 해당 스테이지 case에 새 타입 설정 추가
2. `OnGoblinKilledForMission()`: 새 타입 파라미터 추가
3. `OnGoblinKilled` 이벤트: bool 파라미터 추가

### Step 6: 미션 데이터

**Mission1StageData.cs** (Assets/Scripts/Data/Mission1StageData.cs):
- 해당 스테이지에 `MissionData { type = MissionType.RemoveEnemy, targetEnemyType = EnemyType.NewType, targetCount = N }` 추가

### Step 7: 보조 시스템

1. **StageManager.cs**: `ReportGoblinKill()` 파라미터 추가
2. **EditorTestSystem.cs**: 몬스터 테스트 버튼에 새 타입 추가 (`MONSTER_CYCLE` 배열)
3. **UIManager.cs**: 미션 아이콘에 새 타입 표시 추가
