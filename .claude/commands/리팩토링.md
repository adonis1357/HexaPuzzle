## 리팩토링 체크리스트

$ARGUMENTS 를 리팩토링합니다.

1. **현재 상태 분석**: 대상 코드를 읽고 문제점을 식별합니다.
2. **의존성 매핑**: 이 코드를 참조하는 모든 파일을 찾습니다.
3. **리팩토링 계획**: 변경 전/후를 설명합니다. 동작 변경 없음을 보장합니다.
4. **단계별 수정**: 한 번에 하나의 리팩토링만 수행합니다.
5. **각 단계 후 컴파일 검증**: 매 수정 후 dotnet build 실행합니다.
6. **상태 머신 영향 확인**: GameManager 상태 전환에 영향이 없는지 확인합니다.
7. **결과 보고**: 리팩토링 내용 요약, 변경 파일 목록, 코드 품질 개선 사항을 보고합니다.

모든 응답은 한국어로 작성합니다.
