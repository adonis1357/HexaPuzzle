## 버그 수정 체크리스트

다음 단계를 순서대로 수행하세요:

1. **문제 분석**: $ARGUMENTS 에 대해 관련 소스 파일을 읽고 버그 원인을 파악합니다.
2. **영향 범위 확인**: 버그가 영향을 미치는 시스템들을 나열합니다.
   - 코어 루프: InputSystem → RotationSystem → MatchingSystem → BlockRemovalSystem → GameManager → StageManager
3. **수정 계획 제시**: 수정할 파일과 변경 내용을 사전에 설명합니다.
4. **코드 수정**: 최소한의 변경으로 버그를 수정합니다.
5. **컴파일 검증**: dotnet build로 컴파일 에러가 없는지 확인합니다.
6. **캐스케이드 안전성 확인**: 수정이 캐스케이드 루프의 수렴성에 영향을 주지 않는지 확인합니다.
7. **결과 보고**: 수정 내용, 변경된 파일, 테스트 포인트를 보고합니다.

모든 응답은 한국어로 작성합니다.
