$ARGUMENTS 에 대해 코드 리뷰를 수행합니다.

## 검토 항목 (7가지)

1. **코딩 컨벤션**: 기존 패턴과의 일관성 (이펙트 생성, 애니메이션 코루틴, 색상 헬퍼)
2. **좌표 검증**: 그리드 접근 전 IsValidCoord() / IsInGameField() 호출 여부
3. **이펙트 정리**: Destroy() 누락, raycastTarget=false 설정, effectParent 부모 지정
4. **캐스케이드 안전성**: 무한 루프 가능성, 최대 반복 제한 확인
5. **상태 머신**: GameManager 상태 외부 수정 여부
6. **null 참조**: 그리드 경계, 블록 삭제 후, 코루틴 내 오브젝트 파괴 시 null 체크
7. **성능**: 핫 패스(캐스케이드 루프, 낙하 물리, ProjectileExitPhase)에서 불필요한 GC 할당

모든 응답은 한국어로 작성합니다.
