## 스킬트리 추가 체크리스트

$ARGUMENTS

다음 4단계를 순서대로 수행하세요. 모든 응답은 한국어로 작성합니다.

---

### Step 1: SkillData.cs (Assets/Scripts/Data/SkillData.cs)

1. **SkillType enum에 새 값 추가** (라인 16-69)
   - 범주별 100번대 사용 (기존: 100=드릴이동, 200=폭탄이동, 300=넉백, 400=폭탄데미지, 500=드릴강화, 550=드릴쿠션, 600=드론, 700=망치, 800=스왑, 900=라인)
   - 빈 번호대 선택 (예: 1000번대~)
   - 3단계 체인: `NewSkill1 = 1000, NewSkill2 = 1001, NewSkill3 = 1002`

2. **InitializeSkills()에 SkillNodeData 3개 추가**
   ```
   필수 필드:
   - skillType: enum 값
   - skillName: "스킬 이름 I/II/III"
   - description: 게임 내 표시 설명
   - usageDescription: 사용 방법 설명
   - skillPointCost: SP 비용 (보통 1)
   - goldCost: 골드 비용 (200~500)
   - prerequisite: 선행 스킬 (1단계=None, 2단계=1단계, 3단계=2단계)
   - nodeColor: UI 노드 색상 (기존 색상과 구분)
   - iconSymbol: 프로시저럴 아이콘 유니코드 문자
   ```

3. **헬퍼 메서드 추가** (라인 120-228 패턴)
   ```csharp
   public static List<SkillNodeData> GetNewSkillCategory()
   {
       return _allSkills.Where(s => (int)s.skillType >= 1000 && (int)s.skillType < 1100).ToList();
   }
   ```

### Step 2: SkillTreeManager.cs (Assets/Scripts/Managers/SkillTreeManager.cs)

**GetXxxBonus() 메서드 추가** (라인 182-280 패턴)
```csharp
public int GetNewSkillBonus()
{
    if (IsSkillUnlocked(SkillType.NewSkill3)) return 3;
    if (IsSkillUnlocked(SkillType.NewSkill2)) return 2;
    if (IsSkillUnlocked(SkillType.NewSkill1)) return 1;
    return 0;
}
```

### Step 3: SkillTreeUI.cs (Assets/Scripts/UI/SkillTreeUI.cs)

1. **Y좌표 결정** (라인 281-312)
   - 기존 최하단: lineY = -860f
   - 새 체인: `float newSkillY = -1000f;` (기존과 겹치지 않게)

2. **CreateSkillNodes()에 호출 추가** (라인 293-312 패턴)
   ```csharp
   CreateSkillChain(contentParent, SkillData.GetNewSkillCategory(),
       startX, newSkillY, "새 스킬", new Color(R, G, B));
   ```

3. **스크롤 영역 확장** — contentHeight 값 확인 (새 Y좌표가 포함되도록)

4. **(선택) 새 아이콘 패턴** — 기존 CreateDrillIcon/CreateBombIcon 재활용 또는 새 메서드 작성

### Step 4: 게임플레이 연동

**해당 시스템 코드에서 효과 적용:**
```csharp
int level = SkillTreeManager.Instance != null
    ? SkillTreeManager.Instance.GetNewSkillBonus() : 0;
// level에 따라 동작 변경
```
