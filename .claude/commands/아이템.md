## 아이템 체크리스트

$ARGUMENTS

기존 아이템 패턴(Item + Gauge 쌍)을 반드시 따릅니다. 모든 응답은 한국어로 작성합니다.

---

### Step 1: 기존 패턴 확인

Assets/Scripts/Items/ 하위 기존 4종 구조 확인:
- **HammerItem.cs** + HammerGauge.cs (망치 — 블록 직접 파괴)
- **SwapItem.cs** + SwapGauge.cs (스왑 — 블록 위치 교환)
- **LineDrawItem.cs** + LineGauge.cs (라인 — 한붓그리기 블록 제거)
- **ReverseRotationItem.cs** (역회전 — 게이지 없음)

공통 패턴:
- `Activate()` / `Deactivate()` — 아이템 활성/비활성
- 게이지 상태: `Inactive → Ready → UseReady`
- `AddGauge(amount)` — 매칭/턴 종료 시 게이지 충전
- `ConsumeGauge(amount)` — 사용 시 소모
- MP 비용: `MPManager.Instance.TryConsumeMP(cost)`

### Step 2: 아이템 스크립트 생성

`Assets/Scripts/Items/XxxItem.cs` 생성:
- `[SerializeField]` 참조: Button, HexGrid, BlockRemovalSystem, InputSystem
- `Activate()` — 오버레이 표시, 입력 모드 전환
- `Deactivate()` — 오버레이 해제, 입력 복원
- `OnButtonClicked()` — MP 체크 → Activate/Deactivate 토글
- 실행 로직 — 블록 선택/드래그 → 효과 적용
- 이펙트 — ScreenShake, HitStop, ZoomPunch 등

### Step 3: 게이지 스크립트 생성 (필요 시)

`Assets/Scripts/Items/XxxGauge.cs` 생성:
- 싱글톤 패턴 (`public static XxxGauge Instance`)
- 상태 enum: `GaugeState { Inactive, Ready, UseReady }`
- `AddGauge(int amount)` — 게이지 충전
- `ConsumeGauge(int amount)` — 사용 시 소모
- `GetUseReadyLevel()` — 스킬 레벨에 따른 사용 레벨 반환
- UI 갱신: `RefreshUI()`, `ForceRefreshUI()`

### Step 4: 시스템 연동

1. **InputSystem.cs**: 아이템 UseReady 상태 체크 → 회전 입력 블록
2. **GameManager.cs**: 아이템 버튼 UI 생성 (CreateItemButtons 패턴)
3. **UIManager.cs**: 아이템 배지/MP 비용 표시
4. **MPManager.cs**: `ItemType` enum에 새 아이템 추가 + MP 비용 설정

### Step 5: 스킬트리 연동 (해당 시)

- **SkillData.cs**: 아이템 레벨 스킬 enum 추가 (100번대 단위)
- **SkillTreeManager.cs**: `GetXxxLevel()` 메서드 추가
- **SkillTreeUI.cs**: 아이템 그룹에 스킬 체인 추가

### Step 6: 컴파일 검증

`dotnet build "Assembly-CSharp.csproj"` 성공 확인.

### Step 7: 결과 보고

추가된 아이템 사양, 변경 파일 목록, 테스트 포인트를 보고합니다.
